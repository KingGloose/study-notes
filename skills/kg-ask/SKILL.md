# kg-ask · 库内检索与问答

知识库的价值在**被查**，不在被写。本 skill 是查的入口。

## 何时用

- 「我之前记过 X 吗」「库里关于 X 有什么」
- 主人问技术问题，而这问题**可能已经沉淀过**（尤其前端/网络/AI 这几个已有页的领域）
- 写新 wiki 页之前——先查有没有重复、有没有该建双链的相关页
- 回答前想确认"哪些是他记过的，哪些要我补"

## 为什么不用裸 grep

`archive/` 有 975MB（6790 张图），grep 全库要 **9 秒**。
本脚本只索引 md 文本（全库仅 3.7MB），**构建 0.2 秒、查询 60 毫秒**。

## 用法

```bash
cd 学习笔记/skills/kg-ask && source ../.venv/bin/activate

python scripts/search_vault.py "泛域名 证书"           # 检索（自动建/更新索引）
python scripts/search_vault.py "Agent 架构" --scope wiki  # 只搜沉淀页，不含旧笔记
python scripts/search_vault.py "xxx" --context 3        # 片段多给几行上下文
python scripts/search_vault.py "xxx" --json             # 结构化输出
python scripts/search_vault.py --stats                  # 看库构成
python scripts/search_vault.py --rebuild                # 强制重建索引
```

参数：`--limit`(返回几个文件,默认8) | `--snippets`(每文件几个片段) |
`--min-score`(相关度门槛,默认8.0) | `--scope`(wiki/index/raw/archive)

索引存 `.vault-index.json`，文件变更时自动重建（已被 gitignore）。

## 分区权重（对应 AGENTS.md 三层）

| 分区 | 权重 | 含义 | 输出标记 |
|------|------|------|----------|
| `wiki` | 3.0 | AI 沉淀的知识，**含个人判断，最高优先** | ★ 沉淀 |
| `index` | 2.0 | 唤醒索引（知道知识点存在） | ◇ 索引 |
| `raw` | 1.2 | 原始资料留档 | · 原文 |
| `archive` | 0.8 | 旧世界封存，兜底但不可忽略 | ▫ 旧笔记 |

## 回答纪律（本 skill 存在的核心理由）

拿到检索结果后，**必须按来源分层回答**：

1. **库里有 wiki 沉淀** → 以那页为主，说明"你在 `wiki/xxx` 记过这个"，
   引用其中的个人判断/踩坑/项目上下文。
2. **只有 archive 旧笔记** → 说明"这是旧笔记里记过的，可能已过时"，
   按 AGENTS.md：**旧笔记原文不动**，若值得升级则提议蒸馏成 wiki 页。
3. **只有 index 关键词** → 说明"你知道这个知识点存在但没写详细页"，然后补通用知识。
4. **库里完全没有** → **必须明说「库里没有记录，以下是我的通用知识」**。
   脚本在无命中时会直接打这条提示，别忽略它。

**绝对不要**把 AI 的通用知识说成"你之前记过"——这会污染主人对自己知识库的判断，
是 AGENTS.md 明令禁止的（"不要在回答里把'笔记记过的'和'AI 补充的'混在一起不加区分"）。

## 检索技巧

- **中文长词会自动拆子串**：查"模块缓存单例"会拆出"模块/缓存/单例/块缓存…"，提高召回。
  副作用是可能碰巧命中无关文件，所以有 `--min-score` 门槛（默认 8.0）过滤弱命中。
- **换说法重试**：库里用词可能和主人当下的说法不同（如"泛域名"vs"通配符域名"）。
- **写新页前先 `--scope wiki` 查一遍**，避免重复沉淀、顺便找出该建双链的页。
- 结果为空不代表没价值——**那正是"该沉淀"的信号**。

## 与其他 skill 的配合

```
主人问技术问题
  → kg-ask 先查库（本 skill）
  → 有沉淀：基于它回答，必要时补充
  → 没沉淀且值得记：走摄入 skill（kg-doc/kg-zhihu/...）→ 沉淀
写新 wiki 页前
  → kg-ask --scope wiki 查重 + 找双链候选
  → kg-lint 事后体检（孤儿页/死链）
```

## 已验证

- 索引 262 个文件（wiki 17 / index 3 / raw 11 / archive 231），**构建 0.2 秒**。
- 检索"泛域名 证书"：**63 毫秒**，3 个 wiki 页正确排在最前（相关度 53/47/36）。
- 中文拆词有效："模块缓存单例" 正确命中 `wiki/前端/JS 模块系统与模块缓存单例.md`（相关度 216）。
- archive 兜底："Docker 镜像" `--scope archive` 命中旧笔记 `archive/01 基础/03 Docker.md`。
- 无关查询："量子计算 拓扑" 正确报告无沉淀，并过滤掉 63 个拆词误命中的弱结果。
