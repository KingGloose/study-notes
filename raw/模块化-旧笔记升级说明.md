- CommonJS 缓存机制:首次加载无缓存、后续读缓存、**按文件地址(路径)做缓存 key**、`loaded` 属性、深度优先加载、`require.cache`。
- CommonJS 本质:`Module` 实例 + `compiledWrapper` 函数执行结果、exports 与 module.exports 的内存引用关系。
- 寻址规则:核心模块 / node: 前缀 / 相对路径 / node_modules 逐级上溯 / NODE_PATH。
- ESM:语法层解析、静态分析、live binding(模块环境记录实时绑定)、import() 动态导入、顶层 await、Node 的 .mjs / type:module 判定、CJS 与 ESM 互操作。

## 升级补充(旧笔记缺口)
